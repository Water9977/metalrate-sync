# Batch 5, follow-up wave (second touch, not new contacts)

This is a follow-up wave, not a fresh cold-outreach batch. Every person below already got a personalized first email or DM in batches 1-4 (Aug 2026) and none replied. Cold-email data says most replies come from a second touch, not the first send, so giving up after one email was likely the mistake, not the targeting. These are short, honest nudges to the same 82 people, each referencing something true and specific from their original message, ending in one real question, and mentioning the 14-day free trial in the founder's own low-pressure terms (try it, delete it if it's not for you). No link-drops. Grouped in the same order as the original 4 source files for easy reference.

Note on count: the source files (batch3-emails.md, batch4-emails.md, dm-drafts-batch1, dm-drafts-batch2) contain 21 + 22 + 16 + 23 = 82 actual recipients, not 85. The dm-drafts-batch2 file's own intro line says "23 more" and only lists 23 people, three short of the 26 the task brief expected. Every real recipient found across the 4 named files is covered below.
